Comandos Rápidos de Git

Recordatorio de comandos esenciales para la gestión del repositorio local:

# Comprobar estado del repositorio
git status

# Añadir todos los cambios
git add .

# Crear un commit con mensaje descriptivo
git commit -m "Mensaje descriptivo de los cambios"

# Enviar cambios a la rama principal en GitHub
git push origin main

PowerShell Bypass

Para ejecutar scripts locales temporalmente omitiendo restricciones de firma:

Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force
