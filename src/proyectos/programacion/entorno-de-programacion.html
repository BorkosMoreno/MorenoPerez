Detalle de las herramientas y versiones utilizadas para el desarrollo y mantenimiento de este portal:

Especificaciones del Sistema

  • Sugerencia de versión Node.js: v20 o v22 LTS (recomendadas para estabilidad a largo plazo en Eleventy 3.x)

  • Asistencia IA: GitHub Copilot
  • Sistema Operativo: Windows 11
